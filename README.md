# Studio Intervallo — versione per l'esercitazione 3

Questa è una copia del minisito della seconda esercitazione con i sei errori HTML intenzionali corretti. Si usa per leggere CSS e il funzionamento del pulsante «Mostra il dettaglio» durante la terza esercitazione.

Aprire `index.html` nel browser. Tenere insieme `index.html`, `style.css`, `script.js` e la cartella `assets/`.

La griglia dei progetti usa `align-items: start`: quando si chiude il dettaglio di una card, quella card torna alla propria altezza anche se il dettaglio dell'altra è ancora aperto.
